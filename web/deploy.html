把本机已签发的证书上传到数字证书服务，并替换 ALB 的 HTTPS 监听证书。整个过程在本机完成，凭证不落日志。

1 · 选择证书

从本机 certs/ 目录读取。列表按签发时间倒序，最上面一张是最新的。

2 · 阿里云凭证

尚未保存凭证
必须与 ALB 实例所在地域一致，否则查不到监听。证书服务是全局的，不受该值影响。
只调用只读接口，不会产生任何变更

3 · 目标监听

ALB 控制台 → 实例 → 监听，HTTPS 监听的 ID 形如 lsn-e9zuvbx0gwz087g7tq。多个监听会共用同一张上传的新证书。
填一个被该证书覆盖的域名，替换后工具会做一次真实 TLS 握手，比对线上证书序列号，确认替换真的生效。留空则跳过。
高级选项
预演模式下不会产生变更
前提：ALB 上必须已经存在 HTTPS 监听（创建监听时要求绑定一张证书，无法留空）。本工具只做替换与挂载，不创建监听、不改动后端服务器组。
